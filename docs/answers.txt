Q4.
Branches are used in a git repository to allocate a space where developers can edit code without affecting the main branch. Branches also allow multiple members to work and debug on the same source code without affecting or causing error to the main code. They can then merge them in the end.

Q8. 
Inheritance is where one class can inherit properties, methods, and attributes from another class. 

Polymorphism will allow objects of different classes to use the same methods but function differently based on the class type.

Encapsulation keeps data and methods confined in the same class. The data can be controlled through private or public member assignment. 

Q9.
Integration manager workflow has one person merging all changes. The dictator and lieutenants workflow uses lieutenants to merge changes from smaller groups prior to passing them to the dictator who will in the end consolidate everything to the main repository.

Q10
A team of 100 developers would benefit from Dictator and lieutenants workflow by allowing work to be delegated and consolidated into bite size pieces, which will reduce conflicts and collision in the repository.
